「呱呱打字」：适合小朋友入门练习typing的网页版app

小朋友每按对一个键，小青蛙就跳到下一片荷叶，一路跳到终点的荷花。

**怎么玩**
- **荷叶小路（14 课）**：从摸 F、J 上的小凸起开始，按中间一排、上排、下排的顺序一课课学，最后两课是看图打单词（🐱 CAT、🐸 FROG……）。
- **泡泡大作战**：用已经学过的字母戳破往上飘的泡泡，一分钟计分，还会记最高纪录。

**为键盘新手做的设计**
- 屏幕键盘上要按的键会跳动发亮，每根手指有自己的颜色。下面的小手图会亮起该用的手指，并提示「用左手食指按」。
- 按错不扣分，青蛙只会摇摇头，不会打击孩子的信心。完成后按正确率给 1 到 3 颗星。
- 有音效，还会用英文读出字母和单词，可以用右上角的喇叭关掉。
- 如果孩子不小心开着中文输入法，页面会提醒切换到英文。
- 星星和进度会自动保存。没有实体键盘时，也可以直接点屏幕上的按键。
